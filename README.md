# Hila Shaked Portfolio — Homepage V1

Static responsive homepage prototype.

## Preview locally
Open `index.html` after extracting the entire ZIP. Keep the `assets` folder next to it.

## Deploy with GitHub Pages
1. Upload all files and folders in this project to the repository root.
2. In GitHub open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Choose branch **main** and folder **/(root)**, then save.

GitHub will generate a public preview URL after deployment.
